# Order Flow Platform

Distributed order management platform built with **Java, React, PostgreSQL, Azure, Terraform and Event-Driven Architecture**, applying **DDD + Clean Architecture**.

## Tech Stack
- Java 21 + Spring Boot
- React + Vite
- PostgreSQL
- Azure Event Hubs (Kafka API)
- Azure Container Apps
- Terraform
- Azure DevOps
- Docker
- Clean Architecture
- Domain-Driven Design
- Microservices
- Event-Driven Architecture

## Microservices
- Order Service
- Inventory Service
- Payment Service
- Notification Service

## Cloud Architecture
- Azure Container Apps
- Azure Database for PostgreSQL
- Azure Event Hubs
- Azure Container Registry
- Azure Front Door
- Azure Monitor

## Project Goal
Simulate a production-grade distributed order processing platform focused on scalability, resilience, cloud deployment and enterprise architecture best practices.
